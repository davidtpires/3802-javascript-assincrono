# 🚀 JavaScript: Entendendo Promises e Async/Await

Este projeto foi desenvolvido durante o curso **JavaScript: Entendendo Promises e Async/Await** na Alura. O objetivo é aprofundar os conhecimentos em programação assíncrona, explorando o funcionamento de Promises e a utilização do async/await para um código mais legível e eficiente.

🔗 [Acesse o projeto aqui](https://davidtpires.github.io/3802-javascript-assincrono/)

## 📌 Visão Geral

- Compreensão da execução assíncrona no JavaScript.
- Utilização de **Promises** para lidar com operações assíncronas.
- Uso de **async/await** para melhorar a leitura do código.
- Tratamento de erros em operações assíncronas.

## 🛠️ Tecnologias Utilizadas

- **JavaScript (ES6+):** Manipulação de Promises e async/await.
- **HTML5 e CSS3:** Estrutura e estilização básica.
- **GitHub Pages:** Publicação e hospedagem do projeto.
